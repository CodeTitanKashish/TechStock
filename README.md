# 📦 StockSense
 
> Smart Inventory & Warehouse Management System
 
StockSense is an ERP-style inventory management platform that streamlines warehouse operations, inventory tracking, auditing, and analytics through a single centralized system.
 
## 🚀 Features
 
- 📊 Real-time Dashboard
- 📦 Product & SKU Management
- 🏢 Multi-Warehouse & Bin Tracking
- 🔄 Goods Receipts, Deliveries & Transfers
- 📖 Stock Ledger & Audit Logs
- 📈 Reports & Analytics
- 📄 Automated Documentation
 
## 🛠️ Tech Stack
 
- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- JWT Authentication
